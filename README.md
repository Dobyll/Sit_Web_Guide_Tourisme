# Guide touristique – Site web (HTML, CSS, JavaScript, XML)

Projet universitaire réalisé en binôme en L1 Informatique à l'Université de Poitiers.

## Le projet
Site web présentant une collection de lieux touristiques dans quatre pays : l'Albanie, le Brésil, le Cameroun et le Vietnam. Chaque pays a sa page, avec ses activités, ses photos et ses données structurées en XML.

## Fonctionnalités
- Une page par pays, avec les lieux et les activités à découvrir
- Formulaires interactifs écrits en JavaScript, puis en TypeScript
- Données des pays stockées en XML et validées par une DTD
- Feuille de style principale et feuille de style alternative
- Page de présentation des auteurs (portrait chinois) et page d'auto-évaluation

## Notions utilisées
- HTML / XHTML et CSS
- JavaScript et TypeScript, manipulation du DOM
- XML et DTD

## Répartition du code

- **Nadia MOUACHA** : pages, mise en forme et données XML du Brésil et du Vietnam

## Lancer le projet
- Ouvrir `index.html` dans un navigateur.
- Pour recompiler le TypeScript : `cd Code/Typescript && tsc`
